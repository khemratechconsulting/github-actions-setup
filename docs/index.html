How it works

Four steps, most of them automatic.

1

Run the script

From your project root — one command, no config file to write by hand.

2

Pick a deploy target

AWS, Vercel, a generic server, or tests-only if you're not ready to automate deploys yet.

3

Add the secrets it prints

The script tells you the exact names to add under Settings → Secrets and variables → Actions.

4

Push and watch it run

Open a PR to see tests run; merge to main to see the deploy job fire.
